Recreating Apple Liquid Glass in Real-Time

Physically-Based Frosted Glass with Dispersion, Caustics & Specular Highlights

glassrefractionchromatic-aberrationsdfwebglfresnelcaustics

Apple's Liquid Glass design language represents a masterclass in making UI elements feel physical. Behind the elegant frosted panels lies sophisticated light simulation: curved bevels that refract like real lenses, wavelength-dependent dispersion creating rainbow fringes, Fresnel reflections that respond to viewing angle, and caustic bands where light focuses through curved edges. This article breaks down each technique with working GLSL code you can drop into your own projects.

The Squircle: Apple's Signature Shape

Apple doesn't use simple rounded rectangles. They use squircles - superellipses defined by |x/a|^n + |y/b|^n = 1. When n=2, you get an ellipse. When n=4, you get that distinctively smooth Apple corner that doesn't have the abrupt curvature change of a rounded rectangle. As n approaches infinity, it becomes a sharp rectangle.

Squircle Signed Distance Field glsl 
// Superellipse SDF: |x/a|^n + |y/b|^n = 1
// n=2: ellipse, n=4: squircle (Apple style), n→∞: rectangle
float sdSquircle(vec2 p, vec2 size, float n) {
    vec2 d = abs(p) / size;
    float dist = pow(pow(d.x, n) + pow(d.y, n), 1.0 / n);
    return (dist - 1.0) * min(size.x, size.y);
}

// Squircle with corner radius - hybrid approach
float sdSquircleRounded(vec2 p, vec2 size, float radius, float n) {
    vec2 innerSize = size - radius;
    vec2 d = abs(p);
    
    // Inside inner region - pure squircle
    if (d.x <= innerSize.x && d.y <= innerSize.y) {
        return sdSquircle(p, size, n);
    }
    
    // Corner region - blend squircle with rounded corner
    vec2 cornerP = max(d - innerSize, 0.0);
    float cornerDist = length(cornerP) - radius;
    float squircleDist = sdSquircle(p, size, n);
    
    return max(squircleDist, cornerDist);
}

The SDF returns negative values inside the shape, positive outside, with the magnitude being the exact distance to the surface. This gives us pixel-perfect anti-aliasing for free - just use smoothstep() around the zero crossing.

Anti-Aliased Mask from SDF glsl 
float d = sdSquircleRounded(p, halfSize, cornerRadius, 4.0);

// Soft edge mask: 1.0 inside, 0.0 outside
float mask = 1.0 - smoothstep(-edgeSoftness, edgeSoftness, d);

if (mask < 0.001) discard;  // Early-out for transparent pixels

Unified Bevel Geometry

The magic of Liquid Glass comes from the beveled edges that act like tiny lenses. Instead of flat glass, imagine the edges curving outward like a magnifying glass rim. This curvature refracts light, creates specular highlights, and focuses light into caustics. The key insight: compute this bevel geometry ONCE and reuse it for all effects.

The bevel curvature follows the formula 1 - sqrt(1 - x²), which traces the profile of a circular lens. At the center (x=0), the surface is flat. At the edge (x=1), the surface curves away at 45 degrees. This creates physically plausible refraction that looks like real glass.

BevelGeometry Struct & Computation glsl 
struct BevelGeometry {
    vec2 gradDir;      // 2D gradient direction (outward from shape center)
    float bevelAmount; // Surface tilt amount (0 = flat, 1 = max bevel)
    float edgeFactor;  // 0 = center, 1 = at edge
};

BevelGeometry computeBevelGeometry(vec2 uv, vec2 size, float radius, 
                                    float squircleN, float edgeWidth, float bevelDepth) {
    BevelGeometry result;
    
    // Work in pixel space for consistent bevel width
    vec2 p = (uv - 0.5) * size;
    
    // SDF distance - positive inside
    float d = sdSquircleRounded(p, size * 0.5, radius, squircleN);
    float edgeDist = -d;
    
    // Effect zone extends inward from edge
    float effectZone = radius * edgeWidth;
    result.edgeFactor = 1.0 - smoothstep(0.0, effectZone, edgeDist);
    
    // Normalized position within edge zone (0 = inner, 1 = outer)
    float zonePos = clamp(1.0 - edgeDist / effectZone, 0.0, 1.0);
    
    // Physical lens curvature: 1 - sqrt(1 - x²)
    result.bevelAmount = (1.0 - sqrt(1.0 - zonePos * zonePos * bevelDepth)) 
                         * result.edgeFactor;
    
    // Compute gradient via finite differences
    float eps = max(2.0, radius * 0.05);
    float dx = sdSquircleRounded(p + vec2(eps, 0.0), size * 0.5, radius, squircleN) -
               sdSquircleRounded(p - vec2(eps, 0.0), size * 0.5, radius, squircleN);
    float dy = sdSquircleRounded(p + vec2(0.0, eps), size * 0.5, radius, squircleN) -
               sdSquircleRounded(p - vec2(0.0, eps), size * 0.5, radius, squircleN);
    
    // Convert to UV-space gradient
    result.gradDir = normalize(vec2(dx, dy) / size + 0.0001);
    
    return result;
}

Computing the SDF gradient via finite differences (sampling at p±epsilon) gives us the direction the surface is facing. This is cheaper than analytical gradients and works with any SDF shape.

Separable Gaussian Blur with Linear Sampling

Frosted glass needs heavy blur, but naive implementations are expensive. A 2D Gaussian blur with radius 9 would need 81 samples per pixel. Two key optimizations make this practical: separability (split into H+V passes, reducing to 18 samples) and linear sampling (exploit GPU bilinear filtering to halve samples again).

The Linear Sampling Trick

GPUs perform bilinear interpolation in hardware for free. By sampling between texel centers, we get a weighted average of two texels in one fetch. The trick is computing the optimal sample position that produces the same weighted sum as two discrete samples.

9-Tap Gaussian with 5 Fetches glsl 
// Optimized Gaussian weights using linear sampling
// These combine pairs of standard Gaussian taps
float weights[3];
weights[0] = 0.227027027;  // center
weights[1] = 0.316216216;  // combined taps 1+2
weights[2] = 0.070270270;  // combined taps 3+4

// Optimal offsets between texels
float offsets[3];
offsets[0] = 0.0;
offsets[1] = 1.384615385;  // Between texel 1 and 2
offsets[2] = 3.230769231;  // Between texel 3 and 4

vec4 result = texture2D(uSource, vUV) * weights[0];

for (int i = 1; i < 3; i++) {
    vec2 offset = vec2(offsets[i] * texelSize.x * blurRadius, 0.0);
    result += texture2D(uSource, vUV + offset) * weights[i];
    result += texture2D(uSource, vUV - offset) * weights[i];
}

// 5 texture fetches instead of 9, identical quality!

For extra smoothness, follow up with Kawase blur passes. Kawase samples 4 corners plus center in a diamond pattern - just 5 taps that spread exponentially with each pass.

Kawase Blur Pass glsl 
// Ultra-fast blur: 5 samples per pass
// Run multiple passes with increasing offset (1, 2, 3...)
vec2 off = texelSize * uOffset;

vec4 sum = texture2D(uSource, vUV);                        // center
sum += texture2D(uSource, vUV + vec2(-off.x, -off.y));     // corners
sum += texture2D(uSource, vUV + vec2( off.x, -off.y));
sum += texture2D(uSource, vUV + vec2(-off.x,  off.y));
sum += texture2D(uSource, vUV + vec2( off.x,  off.y));

gl_FragColor = sum * 0.2;

Physically-Based Chromatic Aberration

Real glass disperses light - different wavelengths bend at different angles. This is governed by Cauchy's equation: n(λ) ≈ A + B/λ². For crown glass, the refractive indices are approximately: n_red ≈ 1.514, n_green ≈ 1.517, n_blue ≈ 1.524. Red bends least, blue bends most.

We implement this by sampling each color channel at a slightly different UV offset, scaled by the dispersion coefficient for that wavelength.

Per-Channel Refraction with Dispersion glsl 
// Dispersion coefficients based on crown glass
// (relative to green as baseline)
const float disperseR = 0.996;  // Red refracts ~0.4% less
const float disperseG = 1.000;  // Green is baseline
const float disperseB = 1.008;  // Blue refracts ~0.8% more

// Base refraction from bevel geometry
vec2 lensRefract = computeRefraction(bevel);
float refractScale = uRefractStrength * 0.02;

// Scale dispersion effect
float aberrationScale = 1.0 + (uChromaticAberration - 1.0) * 0.5;

// Per-channel UV offsets
vec2 refractR = lensRefract * refractScale * disperseR * aberrationScale;
vec2 refractG = lensRefract * refractScale * disperseG;
vec2 refractB = lensRefract * refractScale * disperseB * aberrationScale;

// Sample each channel at its refracted position
vec3 blurredColor;
blurredColor.r = texture2D(uBlurredScene, mirrorUV(screenUV + refractR)).r;
blurredColor.g = texture2D(uBlurredScene, mirrorUV(screenUV + refractG)).g;
blurredColor.b = texture2D(uBlurredScene, mirrorUV(screenUV + refractB)).b;

The mirrorUV() function reflects UVs that go outside 0-1, preventing hard cutoffs at screen edges: abs(mod(uv + 1.0, 2.0) - 1.0)

Fresnel Reflections: The Physics of Glass

Glass doesn't just refract - it also reflects. The Fresnel equations tell us how much light reflects vs transmits based on viewing angle. At normal incidence (looking straight at glass), about 4% reflects. At grazing angles, nearly 100% reflects. This is why windows become mirrors at shallow angles.

The base reflectance F0 comes from the refractive indices: F0 = ((n1-n2)/(n1+n2))². For glass (n≈1.5) in air (n=1), F0 ≈ 0.04. But here's a subtlety for chromatic aberration: different wavelengths have different refractive indices, thus different F0 values.

Per-Wavelength F0 for Chromatic Specular glsl 
// Base F0 for glass
float F0_base = 0.04;

// CHROMATIC ABERRATION: F0 varies with wavelength
// F0 = ((n1-n2)/(n1+n2))^2  where n depends on λ
// Crown glass refractive indices:
//   Red (656nm):   n ≈ 1.514 → F0 ≈ 0.0408
//   Green (550nm): n ≈ 1.519 → F0 ≈ 0.0417  
//   Blue (486nm):  n ≈ 1.528 → F0 ≈ 0.0432

float dispersion = uChromaticAberration;
float F0_R = F0_base * mix(1.0, 0.96, dispersion);  // Red reflects less
float F0_G = F0_base;                               // Green baseline
float F0_B = F0_base * mix(1.0, 1.06, dispersion);  // Blue reflects more

// Compute specular per channel
float specR = computePhongSpecular(normal, viewDir, lightDir, ..., F0_R);
float specG = computePhongSpecular(normal, viewDir, lightDir, ..., F0_G);
float specB = computePhongSpecular(normal, viewDir, lightDir, ..., F0_B);

specular += lightColor * vec3(specR, specG, specB) * lightIntensity;

Window Reflection Physics

Here's a critical insight many implementations get wrong: for a window-like glass panel facing you, you see reflections of things BEHIND you, not in front. Think about looking at a window during the day - you see the scene outside (transmitted through) and reflections of the room behind you (reflected off the front surface).

Fresnel-Schlick with Reflection Direction Check glsl 
// Fresnel-Schlick approximation
float fresnelSchlick(float cosTheta, float F0) {
    return F0 + (1.0 - F0) * pow(clamp(1.0 - cosTheta, 0.0, 1.0), 5.0);
}

float computePhongSpecular(vec3 normal, vec3 viewDir, vec3 lightDir, 
                           vec3 cameraLookDir, vec3 panelNormal, 
                           float shininess, float F0) {
    // For window reflection: light must be BEHIND camera
    float dotCheck = dot(lightDir, cameraLookDir);
    
    // Tilted edges can catch lights from the side
    float normalTilt = 1.0 - max(dot(normal, panelNormal), 0.0);
    float threshold = mix(0.0, -0.5, normalTilt);
    
    if (dotCheck < threshold) return 0.0;  // Light in front - no reflection
    
    // Reflect light off surface
    vec3 reflectedLight = reflect(-lightDir, normal);
    float RdotV = dot(reflectedLight, viewDir);
    
    if (RdotV <= 0.0) return 0.0;  // Reflected light points away from camera
    
    // Fresnel term
    vec3 halfVec = normalize(viewDir + lightDir);
    float NdotH = max(dot(normal, halfVec), 0.0);
    float F = fresnelSchlick(NdotH, F0);
    
    // Energy-normalized Phong lobe
    float exponent = shininess * shininess / 32.0;
    float normFactor = (exponent + 2.0) / 6.28318530718;
    float specLobe = normFactor * pow(RdotV, exponent);
    
    return F * specLobe;
}

Caustics: Light Focusing Through Curved Glass

Caustics are the bright patterns formed when light refracts through curved transparent surfaces. At our bevel edges, light rays converge like through a lens, creating bright bands. The intensity is proportional to the surface curvature - where rays converge most, we see the brightest caustics.

For chromatic caustics, we apply the same dispersion principle: different wavelengths focus at different positions. Red light bends less (focuses at outer edge), blue bends more (focuses at inner edge). This creates rainbow-like fringes in the caustic bands.

Per-Channel Caustic Calculation glsl 
// Chromatic dispersion for caustics
// Exaggerated for artistic effect (real glass ~2-3% spread)
const float causticDispersionR = 0.70;  // Red focuses at outer edge
const float causticDispersionG = 1.00;  // Green baseline
const float causticDispersionB = 1.40;  // Blue focuses at inner edge

// Offset edge position per wavelength
float edgeR = bevel.edgeFactor * mix(1.0, causticDispersionR, dispersionStrength);
float edgeG = bevel.edgeFactor * causticDispersionG;
float edgeB = bevel.edgeFactor * mix(1.0, causticDispersionB, dispersionStrength);

// Clamp to valid range
edgeR = clamp(edgeR, 0.0, 1.0);
edgeG = clamp(edgeG, 0.0, 1.0);
edgeB = clamp(edgeB, 0.0, 1.0);

// Caustic band shape per channel
// Peak at middle of edge zone, fade at boundaries
float bandR = pow(edgeR * (1.0 - edgeR * 0.5), 0.5 / causticsScale);
float bandG = pow(edgeG * (1.0 - edgeG * 0.5), 0.5 / causticsScale);
float bandB = pow(edgeB * (1.0 - edgeB * 0.5), 0.5 / causticsScale);

// Focusing power scales with curvature squared
float focusingPower = bevel.bevelAmount * bevel.bevelAmount * 8.0;

// Light must be transmitting through glass (behind panel)
float lightTransmission = max(dot(lightDir, panelNormal), 0.0);

// Light aligned with bevel gets focused more
float lightBevelAlign = abs(dot(lightDir, bevelWorldDir));

float baseStrength = focusingPower * lightTransmission * lightBevelAlign;
vec3 causticRGB = vec3(
    max(baseStrength * bandR, 0.0),
    max(baseStrength * bandG, 0.0),
    max(baseStrength * bandB, 0.0)
);

caustics += lightColor * lightIntensity * causticRGB;

The Complete Pipeline

  • Render scene to FBO at full resolution
  • Downsample to half/quarter resolution for blur efficiency
  • Apply separable Gaussian blur (H-pass, V-pass)
  • Optional: Chain 2-3 Kawase passes for extra smoothness
  • Compute bevel geometry once from squircle SDF
  • Sample blurred scene with per-channel refraction offsets
  • Add specular highlights with per-channel F0 values
  • Add caustics with per-channel edge positions
  • Apply tone mapping to match scene post-processing
  • Composite glass panel with alpha from SDF mask

Performance Optimizations

  • Blur at reduced resolution (quarter res is often sufficient) - most detail is lost anyway
  • Use linear sampling to halve texture fetches with zero quality loss
  • Early-out pixels outside panel using SDF mask (discard before any computation)
  • Compute bevel geometry ONCE and reuse for refraction, specular, and caustics
  • On mobile: reduce blur passes, skip chromatic aberration (use single-channel)
  • For multiple glass panels: share the blurred scene buffer between all panels
  • Consider precomputing SDF to a texture for complex shapes

The most expensive part is the blur. Rendering it at 1/4 resolution and upsampling bilinearly saves 16x fillrate with minimal visible difference. The slight softening actually enhances the frosted glass look.

Putting It All Together

The magic of Apple's Liquid Glass comes from the coherent interaction of all these effects. The bevel geometry drives everything: it determines how much the surface curves away from the viewer, which controls refraction strength, specular highlight position, and caustic intensity. By computing this unified geometry once and deriving all effects from it, we get physically plausible behavior where refraction, reflection, and focusing all respond consistently to the same virtual surface.

This technique works beautifully for UI panels, modal dialogs, and floating menus. For curved 3D glass objects (bottles, spheres), you'd need raymarched volumetric approaches instead of this screen-space method.
