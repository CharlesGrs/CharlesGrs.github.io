Frosted Glass with SDF Refraction

Apple LiquidGlass-Inspired Real-Time Effects

glassblursdfrefractionwebglpost-processing

Apple's LiquidGlass design language brought beautiful frosted glass effects into the spotlight. Behind the aesthetic lies clever GPU programming: signed distance fields for smooth rounded corners, edge-aware refraction, and highly optimized blur passes. Let's build a production-ready frosted glass shader.

The Rounded Rectangle SDF

Signed Distance Fields tell us how far any point is from a shape's surface. For a rounded rectangle, negative values are inside, positive values are outside, and the magnitude tells us the exact distance. This enables buttery-smooth edges and distance-based effects.

Rounded Rectangle SDF glsl 
// p = point to test, b = box half-size, r = corner radius
float sdRoundedBox(vec2 p, vec2 b, float r) {
    // Move point toward box center by corner radius
    vec2 q = abs(p) - b + r;
    
    // Outside: distance to nearest corner circle
    // Inside: negative distance to nearest edge
    return min(max(q.x, q.y), 0.0) + length(max(q, 0.0)) - r;
}

The SDF gives us pixel-perfect anti-aliasing for free: simply use smoothstep() around the zero crossing. No jagged edges, no expensive multi-sampling.

Anti-Aliased Mask from SDF glsl 
float d = sdRoundedBox(p, halfSize, cornerRadius);

// Soft edge mask: 1.0 inside, 0.0 outside
// edgeSoftness controls anti-aliasing width (typically 1-2 pixels)
float mask = 1.0 - smoothstep(-edgeSoftness, edgeSoftness, d);

if (mask < 0.001) discard;  // Early-out for fully transparent

Edge Refraction from SDF Gradients

Real frosted glass refracts light, bending it as it passes through curved surfaces. We can compute refraction direction from the SDF gradient using finite differences - sample the SDF at nearby points and measure how the distance changes.

Edge Refraction Computation glsl 
vec2 computeEdgeRefraction(vec2 uv, vec2 size, float radius, float smoothness, float falloff) {
    vec2 p = (uv - 0.5) * size;
    vec2 b = size * 0.5;
    
    float d = sdRoundedBox(p, b, radius);
    
    // Finite differences to compute gradient
    float eps = max(1.0, smoothness);  // Smoothness = sample distance
    float dx = sdRoundedBox(p + vec2(eps, 0.0), b, radius)
             - sdRoundedBox(p - vec2(eps, 0.0), b, radius);
    float dy = sdRoundedBox(p + vec2(0.0, eps), b, radius)
             - sdRoundedBox(p - vec2(0.0, eps), b, radius);
    
    vec2 grad = vec2(dx, dy) / (2.0 * eps);
    
    // Fade refraction as we move away from edges
    float edgeDist = -d;  // Positive inside
    float edgeFade = 1.0 - smoothstep(0.0, radius * falloff, edgeDist);
    
    return grad * edgeFade;
}

The smoothness parameter controls gradient sampling distance. Higher values produce smoother but less sharp refraction. Start with 2.0-4.0 for subtle effects.

Optimized Separable Gaussian Blur

Frosted glass needs heavy blur, but naive implementations are expensive. The key insight: a 2D Gaussian blur is separable into two 1D passes (horizontal, then vertical). This reduces O(N^2) samples to O(2N). But we can go further with linear sampling.

Linear Sampling Optimization

GPUs perform bilinear filtering in hardware for free. By sampling between texel centers, we get a weighted average of two texels in one fetch. This halves our sample count without quality loss.

9-Tap Gaussian with Linear Sampling glsl 
// Optimized Gaussian blur using linear sampling
// These weights/offsets combine pairs of standard Gaussian taps
float weights[3];
weights[0] = 0.227027027;  // center
weights[1] = 0.316216216;  // combined taps 1+2
weights[2] = 0.070270270;  // combined taps 3+4

float offsets[3];
offsets[0] = 0.0;
offsets[1] = 1.384615385;  // optimized offset between texels
offsets[2] = 3.230769231;

vec4 result = texture2D(uSource, uv) * weights[0];

for (int i = 1; i < 3; i++) {
    vec2 offset = direction * offsets[i] * texelSize * blurRadius;
    result += texture2D(uSource, uv + offset) * weights[i];
    result += texture2D(uSource, uv - offset) * weights[i];
}

// 5 texture fetches instead of 9, same quality!

Kawase Blur for Extra Smoothing

For ultra-smooth glass, add Kawase blur passes after Gaussian. Kawase blur samples 4 corners plus center in a diamond pattern - just 5 taps per pass. Multiple passes at increasing offsets create beautiful, soft falloff.

Kawase Blur Pass glsl 
// Ultra-fast blur: 5 samples per pass
vec2 off = texelSize * uOffset;  // Offset increases each pass

vec4 sum = texture2D(uSource, uv);                        // center
sum += texture2D(uSource, uv + vec2(-off.x, -off.y));     // top-left
sum += texture2D(uSource, uv + vec2( off.x, -off.y));     // top-right
sum += texture2D(uSource, uv + vec2(-off.x,  off.y));     // bottom-left
sum += texture2D(uSource, uv + vec2( off.x,  off.y));     // bottom-right

gl_FragColor = sum * 0.2;

Kawase blur was designed for bloom in games like Ratchet & Clank. It's not physically accurate but produces pleasing results with minimal samples.

Chromatic Aberration at Edges

Real glass separates light into its component wavelengths. We simulate this by sampling RGB channels at slightly different offsets, scaled by our refraction gradient.

Edge Chromatic Aberration glsl 
vec2 edgeRefract = computeEdgeRefraction(uv, panelSize, cornerRadius, smoothness, falloff);
vec2 refractOffset = -edgeRefract * refractStrength * 0.01;
vec2 baseUV = screenUV + refractOffset;

vec3 color;
if (chromaticAberration > 0.001) {
    // Aberration scales with refraction strength
    float aberrationAmount = length(edgeRefract) * chromaticAberration * 0.003;
    vec2 aberrationDir = normalize(edgeRefract + vec2(0.001));
    
    // Sample R, G, B at different offsets
    color.r = texture2D(uBlurredScene, baseUV + aberrationDir * aberrationAmount).r;
    color.g = texture2D(uBlurredScene, baseUV).g;
    color.b = texture2D(uBlurredScene, baseUV - aberrationDir * aberrationAmount).b;
} else {
    color = texture2D(uBlurredScene, baseUV).rgb;
}

Performance Considerations

  • Render blur at half or quarter resolution, then upsample - most blur detail is lost anyway
  • Use linear sampling to halve texture fetches with zero quality loss
  • Chain multiple Kawase passes (offsets 1, 2, 3) instead of one massive Gaussian
  • Compute SDF once per panel, not per pixel - store in a texture for complex shapes
  • Early-out pixels outside the panel using the SDF mask
  • Mobile: reduce blur passes from 4 to 2, skip chromatic aberration

For multiple overlapping glass panels, render all blur passes first into a shared buffer, then composite each panel. This avoids redundant blur computation.

The Complete Pipeline

The final shader applies tone mapping to match your scene's post-processing, ensuring the glass blends naturally. A subtle edge highlight (from the SDF gradient) adds that premium glossy feel.

This technique works great for UI panels, modal dialogs, and floating menus. For curved 3D glass surfaces, you'll need raymarched SDFs or mesh-based approaches instead.
